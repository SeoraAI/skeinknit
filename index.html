Every count is a count you will have

The drawing can never disagree with the instructions.

  • Schematic from the numbersDrawn from the stitch counts Skein actually produces, never from a separately typed measurement.
  • Repeat-awarePick a stitch motif and every size holds whole repeats; the note tells you exactly how far a snapped cast-on moved the finished measurement.
  • Honest about the fitSet-in sleeves report the cap-to-armhole ease. A yoke that does not fit its depth says so instead of printing a number that looks fine.
  • Self-checked, every launchHundreds of assertions run against the engine each time the app opens. If one ever failed, you would know before a size knit wrong.
